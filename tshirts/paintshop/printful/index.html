Setting it up

  1. Open the All-Over Print Men’s Crew Neck T-Shirt in Printful’s design maker.
  2. Upload front.jpg, back.jpg and the two sleeve files to their placements, each set to fill.
  3. Set the collar, if it’s a separate placement, to the shirt color (#121214).
  4. In the mockup preview, check that the toast clears the collar and $Daily Bread$ clears the hem.

Every panel is oversized (24 in wide at 150 dpi) so Printful can crop it to the shirt. I couldn’t reach Printful’s template from here, so check each placement in their preview before ordering.
